# Staff onboarding and offboarding

## New starter checklist (IT)
- Manager raises an Onboarding ticket at least 3 business days before the start date with name, role, start date and the shares needed.
- IT creates the account, enrols MFA on day one, assigns a laptop with the standard build, and adds the user to the right file-share groups.
- VPN access is issued only for roles that work remotely.
- First-day pack: Wi-Fi details, printer setup guide, how to raise a ticket.

## Leaver checklist
- Manager raises an Offboarding ticket with the last working day.
- On the last day IT disables the account, revokes VPN peers, removes share access, and collects devices.
- Mail is forwarded to the manager for 30 days if requested.
